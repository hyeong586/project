# 📚 Culture Archive

## 1. 프로젝트 소개

Culture Archive는 도서와 영화를 감상한 후 작품 정보와 개인적인 리뷰를 기록하고 관리할 수 있는 웹사이트입니다.

여러 곳에 흩어져 있는 감상 기록을 한곳에 모아 보관하고, 작성한 리뷰를 쉽게 다시 확인할 수 있도록 제작했습니다.

## 2. 주요 기능

- **메인 페이지**: 프로젝트 소개 및 각 페이지 이동
- **도서 페이지**: 도서 정보와 리뷰 확인
- **영화 페이지**: 영화 정보와 리뷰 확인
- **리뷰 작성 페이지**: 작품 정보, 작성자, 평점, 감상평 입력
- **데이터 저장**: LocalStorage를 활용한 리뷰 데이터 저장

## 3. 실행 화면

### 메인 페이지
메인 화면 및 도서·영화·리뷰 작성 페이지로 이동하는 메뉴

### 도서 페이지
도서 정보와 작성된 리뷰 확인

### 영화 페이지
영화 정보와 작성된 리뷰 확인

### 리뷰 작성 페이지
작품 정보와 개인적인 감상평 입력

※ 각 항목 아래에 실제 웹사이트 실행 화면을 캡처하여 삽입합니다.

## 4. 실행 방법

1. GitHub 저장소를 다운로드하거나 Clone 합니다.
2. 다운로드한 프로젝트 폴더를 Visual Studio Code에서 엽니다.
3. `index.html` 파일을 브라우저에서 실행합니다.
4. 메인 페이지에서 원하는 메뉴를 선택하여 이용합니다.

## 5. 사용한 오픈소스 및 개발 도구

| 구분 | 사용 기술 | 활용 내용 |
|---|---|---|
| 웹 개발 | HTML | 웹페이지 구조 구성 |
| 웹 디자인 | CSS | 페이지 디자인 및 레이아웃 |
| 프로그래밍 | JavaScript | 사용자 입력 및 리뷰 기능 구현 |
| 데이터 저장 | LocalStorage | 브라우저 내 리뷰 데이터 저장 |
| 개발 도구 | Visual Studio Code | 코드 작성 및 수정 |
| 협업 도구 | GitHub | 소스 코드 공유 및 버전 관리 |

- 별도의 외부 오픈소스 라이브러리 및 프레임워크는 사용하지 않았습니다.
- ChatGPT를 코드 작성 및 오류 해결 과정에서 보조적으로 활용했습니다.
- 외부 이미지를 사용한 경우 이미지 출처를 명시했습니다.

## 6. 팀원 및 역할

| 팀원 | 담당 업무 |
|---|---|
| 최형규 | 메인 페이지(index.html) 구성, 리뷰 작성 페이지(write.html) 제작, 작품 이미지 및 소개 콘텐츠 배치 |
| 최종수 | 도서·영화 리뷰 페이지 제작, 입력 폼 디자인 및 CSS 적용, 회의록 작성 및 피드백 반영 |
